# Site institucional Orkestia

Projeto React + TypeScript + Vite, estruturado a partir do vídeo de referência e dos ativos visuais fornecidos.

## Executar localmente

```bash
npm install
npm run dev
```

## Publicação

Após criar um repositório remoto, execute:

```bash
git remote add origin <URL_DO_REPOSITORIO>
git branch -M main
git push -u origin main
```
